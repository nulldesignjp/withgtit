# Language & Operation Rules

## 1. Input Processing
- I will provide instructions in Japanese or English.
- Always interpret the user's intent based on the context, regardless of the language used.

## 2. Coding & Internal Processing (The "Processing" part)
- **All code, variable names, and function names must be in English.**
- **Code comments and documentation within the code must be in English.**
- Logic reasoning during the process should prioritize English for technical accuracy.

## 3. Communication & Reporting (The "Output" part)
- **Always respond to the user in Japanese.**
- Status updates, bug reports, and explanations of changes must be in Japanese.
- When asking for clarification, do so in Japanese.
